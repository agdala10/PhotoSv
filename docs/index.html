🐧 Descargas de Linux

Paquete .deb

Para Linux Mint, Ubuntu, Debian, Pop!_OS y derivados. Instalación nativa: entra en el menú con su icono, asocia los ficheros PSD y añade photosv-cli.

⬇ Descargar .deb (41 MB) 
sudo apt install ./photosv-0.3.0-linux-x86_64.deb
AppImage

Un solo fichero que funciona en cualquier distro sin instalar nada ni pedir contraseña. Ideal para probar o llevar en un pendrive.

⬇ Descargar AppImage (38 MB) 
chmod +x photosv-0.3.0-linux-x86_64.AppImage
./photosv-0.3.0-linux-x86_64.AppImage

Requiere glibc ≥ 2.35 (Ubuntu 22.04+, Debian 12+, Linux Mint 21+). El .deb instala solo sus dependencias de X11/Wayland y GPU; el AppImage las usa del sistema. Para desinstalar el paquete: sudo apt remove photosv.

Instalación

Windows 10/11 (64 bits)
  1. Descarga el ZIP portable y descomprímelo donde quieras.
  2. Ejecuta install.cmd para instalarlo en tu cuenta (accesos directos en el menú Inicio y el escritorio, sin permisos de administrador).
  3. O usa photosv.exe directo en modo portable (con portable.txt al lado).
Linux (Mint, Ubuntu, Debian y derivados)
  1. Descarga el paquete .deb y ejecuta sudo apt install ./photosv-0.3.0-linux-x86_64.deb.
  2. O descarga el AppImage, dale permisos de ejecución y ábrelo con doble clic.
  3. Abre el editor con photosv o convierte desde la terminal con photosv-cli.
